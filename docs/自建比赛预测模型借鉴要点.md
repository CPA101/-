# 自建比赛预测模型 · 借鉴要点

整理日期：2026-11-02｜ 来源：天天有料（app.tiantianyouliao.cn）静态拆解 + 运行时实测（见同目录 分析报告.md、forecast深挖报告.md、forecast运行时补充.md）
定位：把一个商业预测产品拆出来的可复用方法论；结论均标注证据来源，平台自述类说法不当事实用。

---

## 一、值得借鉴

### 1. 模型按问题分工（来自拆解，实锤其产品结构）

天天有料的 7+2 个"模型"不是一个大模型的七个名字，而是七个不同的问题：

| 他的模型 | 回答的问题 | 自建时的对应物 |
|---|---|---|
| 泊松分布 | 全场比分概率分布长什么样 | Poisson / Dixon-Coles 比分模型（地基） |
| Margin 模型 | 胜平负主推什么、备选什么 | 基于评分差/概率差的主推荐 + 次推荐规则 |
| 指数分歧 | 我的判断和市场（机构赔率）哪里不一致 | 自有概率 − 去水市场概率 的分歧度量 |
| 历史同赔 | 历史上相同赔率的比赛后来怎么了 | 按赔率向量找近邻的历史分布（kNN 基线） |
| HE 海外机构 | 多家机构的态度是否一致 | 多源赔率共识/离散度特征 |
| 大神风向标 | 站内高手们押哪边 | 他人信号聚合（自建可替换为任何外部信号源） |
| 绝密情报 | 定性消息面（伤停、战意等） | 非结构化调整项，必须单独记账、单独评估 |
| 智能精选 | 把以上拼成一张可卖的单子 | 合成层放最后，且要有独立回测 |

原则：**一个模型只回答一个问题，合成层最后做、单独验。** 反面教材就是"多因子加权总分"——权重无法证伪，在大乐透 V1 上已被长回测判死（各子规则均未跑赢随机）。

### 2. 泊松的参数化直接抄（运行时实锤）

他接口实际下发的 `poissonDto` 就是经典攻防强度模型的参数：

- 每队四个数：`homeAttack / homeDefend / homeAvgGoal / homeAvgLose`（客队同理）
- 预期进球：λ_主 = 主队进攻 × 客队防守 × 联赛场均进球；λ_客 = 客队进攻 × 主队防守 × 联赛场均进球（主客再乘主场系数）
- 比分概率：P(i,j) = Pois(i; λ_主) × Pois(j; λ_客)，展开成比分表——正是他未付费时扣下不发的 `winScoreMap / drawScoreMap / lossScoreMap`
- 胜平负概率 = 比分表按 i>j / i=j / i<j 求和

自建 v1 照此实现即可。注意：他前端不做任何计算（无阶乘/exp 代码），概率全在后端算好存表——说明这套参数估计（按历史比赛拟合攻防强度）就是模型的全部核心，没有秘密武器。

### 3. 进阶：Dixon-Coles 修正（公开文献，非来自该产品）

独立泊松会低估 0-0、1-0、0-1、1-1 等低比分。Dixon & Coles (1997) 的做法：对这四个比分的概率乘一个修正因子 τ（由参数 ρ 控制），并给历史比赛加时间衰减权重（越近权重越高，半衰期常取数月量级）。这是自建 v2 的标准升级路线，实现成本低、文献和开源实现都现成。

其他可叠加但要逐个过回测门的：Elo 评分（最简基线）、xG 数据回归（有数据源时显著强于进球数）、阵容/伤停特征。**每加一个，先登记、先回测、跑不赢旧版就不上**——沿用策略登记册的做法。

### 4. 市场基准与"指数分歧"（思想实锤，做法要自己补严）

- 赔率去掉水位才是市场概率：隐含概率 q_k = 1/赔率_k，归一化 p_k = q_k / Σq。
- 你的模型概率与 p 的差（分歧）是唯一可能存在 edge 的地方；没有分歧就没有信息优势，只有分歧还不够，分歧必须被回测证明是"你对市场错"而不是"你错市场对"。
- 评估基准就定为去水后的收盘赔率（closing odds）——它相当于大乐透实验里的机选对照组：**跑不赢它，模型不存在。**

### 5. 工程骨架：赛前冻结、存表、赛后回填（运行时实锤）

他的后端结构值得原样借鉴：

- 按日期批量预计算（getDate 返回有数据的日期 + modelCount），结果落表（margin_match_result / poisson_match_result / index_match_result）
- 每场带 `modelSellStopTime`（卖停=预测锁定时刻），赛后回填 `hit / primaryRecStatus / marginUpdateTime`

自建建议的记录 schema（每场每模型一行，落盘后不许改）：

```
match_id, model_name, model_version, frozen_at,
p_home, p_draw, p_away,          # 模型概率
mkt_home, mkt_draw, mkt_away,    # 同场去水市场概率（基准）
score_probs_ref,                  # 比分表存档引用（可选）
result_home, result_away,        # 赛后回填
settled_at, logloss, rps         # 赛后按场计算的评分
```

这张表同时是账本、回测集和校准数据源——和大乐透的主数据表+账本是同一纪律。

### 6. 已赛结果公开可查（实测）

他的已赛场次连推荐编码和命中结果都明文返回，任何人可复核。对自建的启示：**留可复核的记录是对自己诚实的前提**——预测发布即存档，复盘只认存档，不认记忆。

## 二、别学的

1. **命中率话术当评估**。实测 `smart/select/model/hit` 下发的是后端写好的营销句："近1周命中率79%""昨日比分命中10.00倍""近7日命中49场"——窗口任选、不给样本量、不给基准、不给置信区间。自己评估只认：样本量 + 概率评分 + 与基准的差 + 差的显著性。
2. **模型数量当卖点**。7 个模型互不校验、结论冲突时无仲裁规则。自建宁可只有 2 个能打赢基准的，不要 7 个花架子。
3. **只报命中的窗口**。"昨日命中"是幸存者叙事；要报就报全量：全部场次、全部模型、连续窗口，和大乐透复盘"去叙事化"一个标准。
4. **把情报/消息面混进模型分数**。他的绝密情报是单独产品、单独卖——这点反而是对的：定性信息无法回测，就单独记账，别掺进概率里污染评估。

## 三、评估体系（自建必须先于模型定稿）

- **概率评分**：log loss（越低越好）、RPS（Ranked Probability Score，足球胜平负有序三分类的标准评分）、Brier score。只看"命中率"会被高频猜热门骗过去。
- **校准**：把预测概率分桶（如 60–70%），看实际发生率是否落在桶内；长期偏离说明参数估计有系统性偏差。
- **回测方式**：walk-forward——用 t 之前的数据拟合，只预测 t 之后的比赛，滚动前进；**严禁随机切分**（会把未来信息泄漏进训练集，是最常见的自欺）。
- **对照与显著性**：每个窗口同时记录市场基准的同口径评分；模型−基准的差要给样本量和粗略的 z 值/置信区间，差小于噪声就不下结论——与大乐透对照实验"30 期只出初步观察、不作终审"同理。
- **下注层面（如涉及）**：看 CLV（你的下注赔率 vs 收盘赔率）而不是短期盈亏；短期盈亏方差极大，CLV 才是技能的低噪声信号。仓位用分数 Kelly 并设上限。

## 四、数据来源选项（自建视角）

| 来源 | 内容 | 成本/备注 |
|---|---|---|
| football-data.co.uk | 五大联赛多年赛果 + 多家公司赔率 CSV | 免费；练模型与回测管线的最佳起点 |
| API-Football 等公开 API | 赛程、赛果、部分赔率 | 有免费档；注意限额与字段口径 |
| StatsBomb 开放数据等 | 事件级/xG 数据（部分赛事） | 免费但赛事覆盖有限 |
| 纳米体育 / SportRadar 类 B2B 数据商 | 全量实时赛程、赔率、历史赔率库 | 天天有料用的就是这类（纳米实锤、SportRadar 为其自述）；付费、企业向 |
| 竞彩数据自攒 | 官方赛程 + SP + 赛果对齐 | 无现成干净免费源；要自己定时抓取落表，这正是数据商收费的原因 |

先用免费源把"模型+回测+记账"管线练通，再决定要不要为数据花钱——顺序别反。

## 五、落地路线（每级有晋级门槛）

- **v0 基线**：历史同赔 kNN + 去水市场概率，两条对照线先落表。
- **v1 泊松**：攻防强度模型，按日期批量预测、冻结、回填。门槛：walk-forward 下 RPS/log loss 打平市场基准。
- **v2 Dixon-Coles**：加低比分修正与时间衰减。门槛：同口径评分**稳定优于 v1 且不差于基准**，差值过显著性粗筛。
- **v3 特征扩展**：xG、Elo、赔率分歧度等逐个登记、逐个过门，不过门不上线。
- **合成层**：多模型合成只在每个单模型都验完之后做，合成权重同样要回测，禁止拍脑袋配比。

全程纪律沿用现成的：策略登记册（失败的也登记）、账本、对照组、复盘去叙事化。

## 附：公式速查

- 泊松：P(X=k) = λ^k · e^(−λ) / k!
- 去水（等比法）：p_k = (1/o_k) / Σ_j (1/o_j)
- RPS（三分类）：RPS = ½ · Σ_{r=1}^{2} ( Σ_{i≤r} (p_i − e_i) )²，其中 e 为实际结果的独热编码，按 主胜→平→客胜 排序
- Log loss：−ln(p_实际结果)
- 分歧：edge_k = p_model,k − p_market,k（只在有回测支撑的方向上才有意义）
